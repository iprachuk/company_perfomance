# Company Performance Analysis

## Опис проєкту

Цей репозиторій містить комплексний аналіз перформансу компанії на основі даних про транзакції, сесії користувачів та їх географічне розташування.

## Основні компоненти

### 📊 **SQL запити для аналізу**
- **analysis_company_perfomance_by_continent** - детальний SQL запит для аналізу:
  - Доходів за континентами
  - Розбору доходів за типами пристроїв (мобільні та десктопні)
  - Кількості активних облікових записів та верифікованих користувачів
  - Кількості сесій за географічними регіонами
  - Відсоткового розподілу доходів

### 📁 **Залучені таблиці даних**
- `DA.order` - дані про замовлення
- `DA.product` - інформація про продукти
- `DA.session_params` - параметри сесій (включаючи тип пристрою та континент)
- `DA.session` - дані про сесії користувачів
- `DA.account_session` - зв'язок між обліковими записами та сесіями
- `DA.account` - інформація про облікові записи користувачів

### 📈 **Ключові метрики**
- Загальний дохід та розбір за типами пристроїв
- Кількість облікових записів та рівень верифікації
- Активність користувачів (кількість сесій)
- Географічний розподіл продажів

### 📄 **Документація**
- **Company_perfomance.pdf** - детальний звіт з аналізом перформансу компанії

## Використання

Запити можуть бути виконані в BigQuery або інших SQL базах даних, які підтримують аналогічний синтаксис. Результати дозволяють краще зрозуміти:
- Найбільш прибуткові геграфічні регіони
- Тренди користування мобільними та десктопними пристроями
- Ефективність акаунт-верифікації по регіонам
