# Company Performance Analysis

## 📋 Project Description

This repository contains a comprehensive analysis of company performance based on transaction data, user sessions, and geographic information.

The project uses SQL to combine multiple datasets and generate key business metrics related to revenue, customer activity, account verification, and regional performance. The analysis helps identify business trends and supports data-driven decision-making.

---

## 🎯 Project Objectives

The main goals of this project are to:

* Analyze revenue across different continents;
* Compare revenue generated by mobile and desktop users;
* Evaluate user account activity and verification rates;
* Measure user engagement through session counts;
* Identify the most profitable geographic regions;
* Explore customer behavior across different devices.

---

## 🛠️ Technology Stack

* **SQL (Google BigQuery)** – data extraction and analysis;
* **Google BigQuery** – cloud data warehouse;
* **Common Table Expressions (CTEs)** – query organization;
* **Window Functions** – percentage calculations;
* **PDF Reporting** – business performance documentation.

## 📈 Key Metrics

The analysis calculates the following business metrics:

### Revenue Metrics

* Total revenue by continent;
* Revenue generated from mobile devices;
* Revenue generated from desktop devices;
* Percentage contribution to total revenue.

### Customer Metrics

* Total number of user accounts;
* Number of verified accounts;

### User Engagement

* Total user sessions;

## 📊 SQL Analysis Overview

The SQL query consists of two main Common Table Expressions (CTEs):

### Revenue Analysis

Calculates:

* Total revenue;
* Mobile revenue;
* Desktop revenue.

### Customer and Session Analysis

Calculates:

* Number of user accounts;
* Verified accounts;
* Total sessions.

The final query combines these metrics and calculates each continent's contribution to overall revenue using SQL window functions.
